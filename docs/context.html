Scaffold

pnpm workspace, four packages (@lopr/core, lopr cli, @lopr/tui, @lopr/vscode), one shared version 0.1.0. tsup (ESM for core/cli/tui, CJS for the extension), vitest at the root (packages/**/*.test.ts), commitlint + husky commit-msg hook, GitHub Actions CI (typecheck / test / build), eslint flat config via typescript-eslint.

Files: pnpm-workspace.yaml, tsconfig.base.json, vitest.config.ts, eslint.config.mjs, commitlint.config.mjs, .husky/commit-msg, .github/workflows/ci.yml, packages/*/{package.json,tsup.config.ts}.

Decisions taken:

  • Workspace packages resolved to source in tsconfig (paths) so typecheck works before any build; tsup bundles in topological order (core first).
  • TypeScript 5.x, not 7: the native TS7 compiler breaks rollup-plugin-dts (tsup dts: true).
  • pnpm 11: build scripts whitelisted via allowBuilds.esbuild in pnpm-workspace.yaml (the old pnpm.onlyBuiltDependencies in package.json is ignored by pnpm 11; onlyBuiltDependencies in the yaml sets a non-boolean placeholder that does not run the script).
  • TS 7 removed baseUrl; paths are relative to the tsconfig. Not relevant on 5.x but kept clean anyway.
  • "types": ["node"] forced in tsconfig.base — without it process/console are not found in cli/vscode.
  • Core exposes VERSION + PACKAGE_NAME; cli prints help; tui and extension are activation stubs. Smoke test covers the version export.
  • No rootDir/outDir in package tsconfigs: they clash with cross-package source paths; emit is owned by tsup.

Environment: Node 24 LTS installed via fnm, pnpm 11.20 via corepack.

Git gateway

The three-dot diff in core, with the same semantic as a GitHub PR. The unit of review here is the commit range: merge-base(base, head)..head.

Files: packages/core/src/{gateway,diff,config,ignore,types}.ts + diff.test.ts (tests run against throwaway real git repos via test-utils.ts).

Decisions taken:

  • git via child_process, no libgit2. GitGateway interface + GitCli impl; --merge-base form of the three-dot diff (Git 2.30+), the exact semantics GitHub PRs show.
  • Three git calls per diff, run in parallel: --name-status -z (statuses + paths), --numstat -z (additions/deletions, binary detection via -\t-), full unified diff (per-file bodies). Bodies are correlated to entries positionally: all three come from the same git diff machinery (path-sorted), and a length mismatch throws rather than silently misattributing.
  • Renames/copies (-M, git default threshold) carry oldPath; numstat reports the new path, so stats map by new path.
  • lopr.ignore = glob patterns in .lopr/config.json ({"ignore": ["**/dist/**"]}), matched with minimatch (dot: true). The base field lives in the same file; resolution order: CLI/option → config → git default branch (main/master) → clear error.
  • Binary files: binary: true, zero add/del counts, body kept (they will never be anchored later).
  • Traps hit: vitest root include is cwd-relative — switched to **/*.test.ts so a per-package vitest run finds its own tests; git symbolic-ref --short -q HEAD falls back to HEAD for detached state; maxBuffer raised to 64 MiB for large agent-loop diffs.
